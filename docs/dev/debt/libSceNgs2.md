- [sceNgs2ParseWaveformUser, sceNgs2SystemEnumHandles, sceNgs2SystemEnumRackHandles](../../../core/libs/prx/libSceNgs2/PendingExports.cpp) (libSceNgs2) - implemented in `libSceNgs2.native/src/System.cpp` from the firmware 11.00 module. `sceNgs2ParseWaveformUser` reads offset 0 with the caller's read handler, takes the RIFF size from the header and parses the bytes with the shared waveform parser; a null handler returns `0x804A0408` and a null output `0x804A0053`. The enumerators return the count of live systems or racks and fill up to the requested count; a null output with a nonzero count returns `0x804A0053` and an unknown system `0x804A0230`.
